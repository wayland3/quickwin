---

对当前未提交的改动做交叉模型评审。你只做评审，**不得修改任何文件**。

## 输入（缺一项就说明缺失，不要猜）

1. 任务 ID 与 `TASKS.md` 中的验收标准原文
2. 改动范围：`git diff`，或改动文件清单 + 完整内容
3. `npm.cmd run verify` 分项结果
4. 规格：`docs/SPEC.md`、`ARCHITECTURE.md`、`WIN32-NOTES.md` 的相关章节

## 评审清单（逐条给结论，不适用写「N/A + 原因」）

| # | 检查项 | 依据 |
|---|---|---|
| 1 | 验收标准逐条可复现 | TASKS.md |
| 2 | 行为/边界与 PRD 一致（空、超长、失败、权限） | PRD |
| 3 | 分层未越界（platform 唯一出口、ipc.ts 唯一 invoke 入口） | AGENTS §2 #1/#2 |
| 4 | 无新增 `unwrap` / `expect` / 裸 panic / `any` | §2 #3、§6 |
| 5 | schema 变更带 migration + 迁移测试 | §2 #4、§7 |
| 6 | 剪贴板/热键单入口，无绕过 | §2 #5 |
| 7 | 日志不含内容/路径/窗口标题 | §2 #6、§13 |
| 8 | 无未说明的新依赖 | §2 #7 |
| 9 | 测试覆盖是否够（对照 §8 测试要求表） | §8 |
| 10 | `unsafe` 有 SAFETY 注释且仅存在于 `platform/` | §6 |
| 11 | 阻塞 Win32 调用未进入 async 上下文 | §6 |
| 12 | 错误码稳定、中文文案可操作 | ARCHITECTURE §12 |
| 13 | 是否夹带无关改动 | §2 #9 |

## 输出格式

**结论：PASS / FAIL**

| 级别 | 问题 | 位置 | 依据 | 建议 |
|---|---|---|---|---|
| 阻断 | ... | `path:line` | AGENTS §2 #3 | ... |
| 建议 | ... | `path:line` | PRD §x | ... |

判定规则：任何「阻断」项存在即 FAIL；只有「建议」项可 PASS。
不要复述实现者的话，不要评价风格偏好，不要给出「整体不错」这类空话。
