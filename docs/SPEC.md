## 1. 目标与非目标

### 1.1 目标

- 常驻 Windows 的轻量工具，两组热键覆盖：**打开东西、粘贴东西**。
- 默认配置开箱可用；所有关键行为可在设置里改。
- 冷启动快、空闲占用低、不打扰、不泄露剪贴板内容。

### 1.2 非目标（v1 不做）

- 跨平台（macOS / Linux）。
- 云同步、账号体系。
- 密码管理、剪贴板端到端加密存储。

## 2. 典型场景

| 场景                                  | 期望                                             |
|---------------------------------------|--------------------------------------------------|
| 想打开 Chrome 但不想找图标            | `Alt+Space` → `chr` → `Enter`                    |
| 刚复制了三个链接，想粘第二个          | `Alt+V` → 看到历史 → 方向键选 → `Enter`          |

## 3. 全局约定

### 3.1 热键

| 动作           | 默认        | 可改 |
|----------------|-------------|------|
| 打开启动器     | `Alt+Space` | 是   |
| 打开剪贴板历史 | `Alt+V`     | 是   |

- 注册失败不静默：托盘气泡 + 设置页红色标记，并给出备选（`Ctrl+Alt+Space` 等）。
- 同一时刻只有一个浮层可见；在任一浮层内按另一个热键会切换模式而不是叠加窗口。
- 浮层打开时再次按同一热键 → 关闭（切换语义）。

### 3.2 浮层通用行为

- 显示位置：鼠标所在显示器工作区，水平居中，垂直距顶 20%。
- 失焦隐藏（设置可关）；`Esc` 隐藏；隐藏后焦点回到触发前的窗口。
- 不进入任务栏，不出现在 `Alt+Tab`。
- 显示时保留上一次的模式与查询词（启动器保留，剪贴板清空搜索词）。

### 3.3 错误提示

- 所有失败都落到浮层内的一行提示或系统 toast，文案必须说明**下一步能做什么**。
- 禁止出现 `HRESULT`、`0x8007...`、堆栈给最终用户；这些只进日志（不含内容）。

## 4. UI 基础规格

### 4.1 窗口

| 项 | 值 |
|---|---|
| 浮层宽度 | 720px |
| 浮层高度 | 动态 120–560px，超出内容区滚动 |
| 圆角 | 12px |
| 阴影 | `0 16px 48px rgba(0,0,0,.32), 0 2px 8px rgba(0,0,0,.24)` |
| 水平位置 | 目标显示器工作区居中 |
| 垂直位置 | 工作区顶部 + 20% 高度 |
| 背景 | 见配色 token；不使用亚克力/云母（首版性能优先） |
| 设置窗口 | 880×600，可缩放，最小 720×520 |

浮层不显示标题栏、不显示关闭按钮；`Esc` 与失焦即关闭。

### 4.2 配色 token

跟随系统主题（`prefers-color-scheme` + Tauri 主题事件），只维护两套：

| token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--bg` | `#1c1c1e` (96%) | `#ffffff` (96%) | 面板底 |
| `--surface` | `#2c2c2e` | `#f5f5f7` | 输入框、分组底 |
| `--surface-hover` | `#3a3a3c` | `#ececf0` | 悬停 |
| `--surface-active` | `#48484a` | `#e3e3e8` | 选中行 |
| `--text` | `#f5f5f7` | `#1d1d1f` | 主文字 |
| `--text-muted` | `#98989d` | `#6e6e73` | 次要信息 |
| `--text-faint` | `#6e6e73` | `#a1a1a6` | 时间、提示 |
| `--border` | `rgba(255,255,255,.08)` | `rgba(0,0,0,.08)` | 分隔线 |
| `--accent` | `#0a84ff` | `#007aff` | 主色、选中指示 |
| `--warn` | `#ff9f0a` | `#c93400` | 截断、超限 |
| `--danger` | `#ff453a` | `#d70015` | 删除、错误 |

透明度通过 `rgba` 叠加，不使用 CSS `backdrop-filter`（WebView 合成开销大）。

### 4.3 字体与间距

- 字体：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", sans-serif`。
- 正文 13px / 行高 20px；标题 15px / 600；元信息 11px。
- 等宽（预览）：`"Cascadia Mono", Consolas, monospace` 12px。
- 间距基数 4px：行内 8、行间 4、区块 12、面板边距 12。
- 列表行高 44px（单行）/ 56px（双行）；图标 20px；圆角 8px。

### 4.4 通用骨架

```
┌──────────────────────────────────────────────┐
│ 搜索/输入区（44px，含模式图标与过滤 chip）        │
├──────────────────────────────────────────────┤
│ 列表区（可滚动，最多 12 行可见）                 │
│                                              │
├──────────────────────────────────────────────┤
│ 底部提示条（28px，快捷键提示 / 状态 / 计数）      │
└──────────────────────────────────────────────┘
```

- 输入区左侧：当前模式图标（启动器/剪贴板）。
- 输入区右侧：过滤 chip（剪贴板模式）。
- 底部提示条随选中项变化，例如 `Enter 粘贴 · Ctrl+Enter 仅复制 · Ctrl+P 置顶`。
- 无内容时输入区下方显示空态，高度收缩。

### 4.5 键盘

| 场景 | 按键 | 行为 |
|---|---|---|
| 全局 | `Alt+Space` / `Alt+V` | 打开对应模式；已打开则关闭或切换 |
| 全局 | `Esc` | 关闭浮层 |
| 通用 | `Ctrl+,` | 打开设置 |
| 启动器 | `↑` `↓` | 移动选中 |
| 启动器 | `Enter` | 打开 |
| 剪贴板 | `↑` `↓` / `PgUp` `PgDn` | 移动 |
| 剪贴板 | `Enter` | 粘贴 |
| 剪贴板 | `Ctrl+Enter` | 仅复制 |
| 剪贴板 | `Ctrl+P` | 置顶切换 |
| 剪贴板 | `Delete` / `Shift+Delete` | 删除 / 永久删除 |
| 剪贴板 | `Ctrl+Shift+Delete` | 打开清空历史确认 |
| 剪贴板 | `Tab` / `Shift+Tab` | 切换类型过滤 |
| 输入框 | `Ctrl+A` / `Ctrl+C` / `Ctrl+V` | 标准编辑行为 |

规则：

- 焦点永远在输入框，方向键由列表拦截（`preventDefault`）。
- 鼠标悬停不改变选中项（避免误操作），点击才选中。
- 滚轮只滚动列表，不移动选中。
- 输入法组合期间（`compositionstart` 到 `compositionend`）不响应方向键与回车。

### 4.6 状态

| 状态 | 呈现 |
|---|---|
| 加载中 | 3 行骨架，透明度 40%，不显示 spinner |
| 空历史 | 图标 + 「还没有记录」+ 「复制任意内容后会出现在这里」 |
| 无搜索结果 | 「没有找到 "xxx"」 |
| 索引构建中 | 底部提示条右侧显示「索引中 1,204/8,000」 |
| 错误 | 提示条变 `--warn`，显示中文原因与下一步；不弹模态框 |

### 4.7 动效

- 显示：120ms，透明度 0→1 + 位移 4px→0（`ease-out`）。
- 隐藏：80ms 淡出，不做位移动画。
- 高度变化：120ms（内容切换时），列表滚动不做动画。
- 系统开启「减少动画」时全部改为即时切换。
- 禁止：弹跳、缩放、模糊过渡。

### 4.8 可访问性

- 对比度：正文 ≥ 4.5:1，次要信息 ≥ 3:1。
- 可聚焦元素有 2px `--accent` 焦点环（`outline-offset: 2px`）。
- 所有图标按钮有 `aria-label`；列表行有 `aria-selected`。
- 不依赖颜色单独传达状态（截断/置顶同时有文字或图标）。
- 屏幕阅读器：模式切换时播报标题与结果数量（`aria-live="polite"`）。

### 4.9 实现约定

- 全部使用 Tailwind + CSS 变量；颜色不写死在组件里。
- 列表虚拟化：可见行 ≤12，首版不做虚拟滚动；超过 200 条只渲染可视区域。
- 图标：本地 SVG（Lucide 风格），不引图标库；尺寸统一 20px，`stroke-width: 1.75`。
- 图片通过 Tauri `asset` 协议加载 `blobs/` 与缩略图，禁止 base64 内联大图。
- 组件命名：`ItemRow`、`PreviewPane`、`KeyHint`、`EmptyState`、`Skeleton`。

## 5. 功能一：启动器

### 5.1 输入解析

| 输入                                | 行为                                                     |
|-------------------------------------|----------------------------------------------------------|
| 纯文本                              | 应用搜索                                                 |
| `> <命令>`                          | 内置命令（锁屏、睡眠、设置、清空剪贴板、重建索引、退出） |

内置命令清单可在设置中查看。

### 5.2 结果与排序

- 最多 12 条，分组：应用 / 命令。
- 匹配优先级：完全前缀 > 词首缩写（`vsc` → Visual Studio Code）> 子串 > 模糊。
- 同分时按 frecency：`score = 匹配分 × (1 + ln(1+使用次数)) × 时间衰减`，衰减半衰期 14 天。

### 5.3 结果动作

| 按键          | 行为                                             |
|---------------|--------------------------------------------------|
| `Enter`       | 打开                                             |

执行失败时保留面板并提示原因（应用已卸载 / 无权限 / 找不到关联程序）。

### 5.4 启动器 UI

```
[🔍 chr                                        ]
─────────────────────────────────────────────
[icon] Chrome           应用
[icon] Chrome Canary    应用
─────────────────────────────────────────────
Enter 打开
```

- 分组标题 11px、`--text-faint`，上下 6px 间距。
- 选中行：`--surface-active` + 左侧 2px `--accent` 竖条。
- 副标题（路径/来源）单行省略，中间省略号优先保留文件名。

### 5.5 验收

- 输入 `chr` 首条为 Chrome；输入 `vsc` 首条为 VS Code（若已安装）。
- 连续执行 20 次打开操作，面板每次都能被热键重新唤起。
- 搜索结果出现到可键盘操作 ≤ 100ms（索引已就绪）。

## 6. 功能二：剪贴板历史

### 6.1 记录类型

| 类型     | 来源格式            | 存储                        |
|----------|---------------------|-----------------------------|
| 文本     | `CF_UNICODETEXT`    | `text` + `preview`          |
| 富文本   | `CF_HTML`、`CF_RTF` | 原始格式 + 纯文本预览       |
| 图片     | `CF_DIB` / PNG      | `blobs/` 原图 + 缩略图      |
| 文件列表 | `CF_HDROP`          | JSON 数组（路径、是否存在） |

不记录：空内容、纯空白、仅格式无内容。

### 6.2 入库规则

- 去重键：`sha256(kind + 规范化内容)`。重复内容**不新增条目**，只增加计数并刷新最后使用时间（升到列表顶部）。
- 文本预览保留前 512 字符，去除控制字符；全文上限 256KB，超出截断并标记「已截断」。
- 图片上限 8MB，超出只保留缩略图并标记「原图过大」。
- 来源应用：进程名、窗口标题（标题可能含敏感信息，**不参与搜索、不写日志**）。
- 入库延迟 ≤ 300ms。

### 6.3 面板交互

- `Alt+V` 打开，聚焦搜索框，默认显示最近 50 条。
- 搜索：中文 1 字起即时过滤（1–2 字回退 `LIKE`，≥3 字走 FTS）；防抖 80ms。
- 筛选：`Tab` 循环 全部 / 文本 / 图片 / 文件 / 收藏。
- 键盘：↑↓ 选择；`Enter` 粘贴；`Ctrl+Enter` 仅复制；`Ctrl+P` 置顶/取消；`Delete` 删除；`Shift+Delete` 永久删除；`Esc` 关闭。
- 列表项显示：类型图标、首行摘要（单行省略）、来源应用、相对时间（「3 分钟前」）、置顶标记、尺寸标记。
- 右侧预览：文本全文滚动、图片等比、文件列表带存在状态、底部显示完整来源与时间。
- 选中即预览，不写入剪贴板。

### 6.4 剪贴板 UI

```
[🔍 搜索剪贴板          全部 文本 图片 文件 收藏      1,204 条]
────────────────────────────────────────────────────────────
[📄] 今天的会议纪要…                          微信 · 3 分钟前
[🖼] 截图 2026-10-25 14-02.png                截图工具 · 8 分钟前  📌
[📁] 3 个文件 · report.pdf, data.xlsx          资源管理器 · 1 小时前
────────────────────────────────────────────────────────────
Enter 粘贴 · Ctrl+Enter 仅复制 · Ctrl+P 置顶 · Del 删除
```

- 类型图标：文本 `📄`、富文本 `📝`、图片缩略图 20×20、文件 `📁`。
- 置顶标记 `📌` 放行尾；置顶分组固定在列表顶部，与时间分组之间加分隔线。
- 相对时间：`刚刚` / `N 分钟前` / `N 小时前` / `昨天 14:02` / `10-20 14:02`。
- 第二行（可选）显示预览摘要，仅当行高 56px 时；默认单行 44px。

### 6.5 预览区

- 宽度 280px，右侧，与列表间 1px `--border`。
- 文本：等宽字体，最多 2000 字符，超出显示「内容较长，已折叠」。
- 图片：等比缩放，最大 240×240，棋盘格背景表示透明。
- 文件：列表显示文件名、目录、是否存在（缺失标红）。
- 底部固定显示来源应用、完整时间、大小、`已截断`/`原图过大` 标记。

### 6.6 激活（粘贴）流程

1. 记录当前前台窗口 → 隐藏浮层。
2. 恢复前台窗口焦点（≤150ms，失败则提示）。
3. 将条目以原始格式写入系统剪贴板（文本/HTML/RTF/图片/文件列表）。
4. 抑制监听 1.5 秒（按内容 hash），**不新增历史、不调整顺序**。
5. 发送 `Ctrl+V`。
6. 条目**保留在系统剪贴板**（与 Win+V 一致，便于手动再粘）。

失败降级：

- 焦点恢复失败或目标提权 → 只写剪贴板 + toast「已复制，请手动粘贴」。
- 目标应用忽略合成按键 → 同上（无法自动检测，用户反馈后加入已知问题）。

可选设置「粘贴后还原原剪贴板」（默认关闭）：开启后第 6 步改为 300ms 后还原步骤 1 之前的剪贴板快照。

### 6.7 保留与容量

| 规则        | 默认值                       | 可改                    |
|-------------|------------------------------|-------------------------|
| TTL         | 15 天（按 `last_copied_at`） | 7 / 15 / 30 / 90 / 永不 |
| 置顶项      | 豁免 TTL 与自动淘汰          | —                       |
| 条数上限    | 10,000                       | 1,000–50,000            |
| 单条文本    | 256KB                        | 否                      |
| 单张图片    | 8MB                          | 否                      |
| blob 总预算 | 500MB                        | 100MB–2GB               |
| 清理时机    | 启动 + 每 6h + 每 200 次写入 | 否                      |

超预算时按「最久未使用且未置顶」淘汰；置顶项永不自动删除，仅在设置页显示占用并提示手动清理。

### 6.8 隐私

- 数据仅本地明文存储（v1）；设置页明确写出这一点，并说明后续可加 DPAPI。
- 日志与崩溃信息不含剪贴板内容、窗口标题、文件路径。

### 6.9 验收

- 复制 20 条不同文本 → 面板按时间倒序显示 20 条，无重复。
- 复制同一条 3 次 → 仍 1 条，顶部显示「×3」。
- 中文搜索 1 个字能过滤；1000 条数据输入到出结果 <50ms。
- 选中历史项回车 → 内容粘到记事本光标处，历史**无新增条目**、顺序不变。
- 系统时间前推 16 天重启 → 未置顶项消失，置顶项保留。
- 关闭「记录图片」后截图不再入库。

## 9. 边界与限制（对用户可见）

1. 管理员权限窗口不支持自动粘贴，只能复制后手动粘贴。
2. 部分全屏独占游戏会遮住浮层；切到无边框窗口模式可正常使用。
3. 极少数应用不响应合成 `Ctrl+V`（如某些远程桌面/虚拟机窗口），需手动粘贴。
4. `Alt+Space` 可能与 PowerToys Run、输入法等冲突，需换绑。
