# UI 规范

目标是「像一个系统自带的面板」：安静、密度高、键盘优先、没有多余装饰。

## 1. 窗口

| 项 | 值 |
|---|---|
| 浮层宽度 | 720px |
| 浮层高度 | 动态 120–560px，超出内容区滚动 |
| 圆角 | 12px |
| 阴影 | `0 16px 48px rgba(0,0,0,.32), 0 2px 8px rgba(0,0,0,.24)` |
| 水平位置 | 目标显示器工作区居中 |
| 垂直位置 | 工作区顶部 + 20% 高度 |
| 背景 | 见配色 token；不使用亚克力/云母（首版性能优先） |
| 设置窗口 | 880×600，可缩放，最小 720×520 |

浮层不显示标题栏、不显示关闭按钮；`Esc` 与失焦即关闭。

## 2. 配色 token

跟随系统主题（`prefers-color-scheme` + Tauri 主题事件），只维护两套：

| token | 暗色 | 亮色 | 用途 |
|---|---|---|---|
| `--bg` | `#1c1c1e` (96%) | `#ffffff` (96%) | 面板底 |
| `--surface` | `#2c2c2e` | `#f5f5f7` | 输入框、分组底 |
| `--surface-hover` | `#3a3a3c` | `#ececf0` | 悬停 |
| `--surface-active` | `#48484a` | `#e3e3e8` | 选中行 |
| `--text` | `#f5f5f7` | `#1d1d1f` | 主文字 |
| `--text-muted` | `#98989d` | `#6e6e73` | 次要信息 |
| `--text-faint` | `#6e6e73` | `#a1a1a6` | 时间、提示 |
| `--border` | `rgba(255,255,255,.08)` | `rgba(0,0,0,.08)` | 分隔线 |
| `--accent` | `#0a84ff` | `#007aff` | 主色、选中指示 |
| `--warn` | `#ff9f0a` | `#c93400` | 截断、超限 |
| `--danger` | `#ff453a` | `#d70015` | 删除、错误 |

透明度通过 `rgba` 叠加，不使用 CSS `backdrop-filter`（WebView 合成开销大）。

## 3. 字体与间距

- 字体：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", sans-serif`。
- 正文 13px / 行高 20px；标题 15px / 600；元信息 11px。
- 等宽（预览、哈希）：`"Cascadia Mono", Consolas, monospace` 12px。
- 间距基数 4px：行内 8、行间 4、区块 12、面板边距 12。
- 列表行高 44px（单行）/ 56px（双行）；图标 20px；圆角 8px。

## 4. 结构

### 4.1 通用骨架

```
┌──────────────────────────────────────────────┐
│ 搜索/输入区（44px，含模式图标与过滤 chip）        │
├──────────────────────────────────────────────┤
│ 列表区（可滚动，最多 12 行可见）                 │
│                                              │
├──────────────────────────────────────────────┤
│ 底部提示条（28px，快捷键提示 / 状态 / 计数）      │
└──────────────────────────────────────────────┘
```

- 输入区左侧：当前模式图标（启动器/剪贴板/转换）。
- 输入区右侧：过滤 chip（剪贴板模式）或检测标签（转换模式）。
- 底部提示条随选中项变化，例如 `Enter 粘贴 · Ctrl+Enter 仅复制 · Ctrl+P 置顶`。
- 无内容时输入区下方显示空态，高度收缩。

### 4.2 启动器

```
[🔍 chr                                        ]
─────────────────────────────────────────────
[icon] Chrome           应用
[icon] Chrome Canary    应用
[icon] 用 Google 搜索 “chr”   网页
─────────────────────────────────────────────
Enter 打开 · Shift+Enter 管理员 · Ctrl+Enter 位置
```

- 分组标题 11px、`--text-faint`，上下 6px 间距。
- 选中行：`--surface-active` + 左侧 2px `--accent` 竖条。
- 副标题（路径/来源）单行省略，中间省略号优先保留文件名。

### 4.3 剪贴板

```
[🔍 搜索剪贴板          全部 文本 图片 文件 收藏      1,204 条]
─────────────────────────────────────────────────────────────
[📄] 今天的会议纪要…                          微信 · 3 分钟前
[🖼] 截图 2026-10-25 14-02.png                截图工具 · 8 分钟前  📌
[📁] 3 个文件 · report.pdf, data.xlsx          资源管理器 · 1 小时前
─────────────────────────────────────────────────────────────
Enter 粘贴 · Ctrl+Enter 仅复制 · Ctrl+P 置顶 · Del 删除
```

- 类型图标：文本 `📄`、富文本 `📝`、图片缩略图 20×20、文件 `📁`。
- 置顶标记 `📌` 放行尾；置顶分组固定在列表顶部，与时间分组之间加分隔线。
- 相对时间：`刚刚` / `N 分钟前` / `N 小时前` / `昨天 14:02` / `10-20 14:02`。
- 第二行（可选）显示预览摘要，仅当行高 56px 时；默认单行 44px。

### 4.4 预览区（剪贴板）

- 宽度 280px，右侧，与列表间 1px `--border`。
- 文本：等宽字体，最多 2000 字符，超出显示「内容较长，已折叠」。
- 图片：等比缩放，最大 240×240，棋盘格背景表示透明。
- 文件：列表显示文件名、目录、是否存在（缺失标红）。
- 底部固定显示来源应用、完整时间、大小、`已截断`/`原图过大` 标记。

### 4.5 转换模式

```
[1735689600                         时间戳（秒）]
─────────────────────────────────────────────────
时间
  转为本地时间            2025-01-01 08:00:00   ← 选中
  转为 UTC                2025-01-01 00:00:00
  转为 ISO 8601           2025-01-01T00:00:00Z
  转为相对时间            10 个月前
  转为 Unix 毫秒          1735689600000
编码
  Base64 编码             MTczNTY4OTYwMA==
哈希
  MD5                     5d41402abc4b2a76b9719d911017c592
─────────────────────────────────────────────────
Enter 替换原文 · Ctrl+Enter 仅复制 · 1–9 直选
```

- 动作名左对齐，结果预览右对齐等宽、`--text-muted`，超宽省略。
- 分组标题 11px；分组之间 8px。
- 检测标签用 chip：`--surface` 底 + `--text-muted` 字；多个类型横向排列。
- 未识别时 chip 显示「未识别类型」，并在列表顶部提示「可直接使用哈希/编码动作」。

## 5. 键盘

| 场景 | 按键 | 行为 |
|---|---|---|
| 全局 | `Alt+Space` / `Alt+V` / `Alt+X` | 打开对应模式；已打开则关闭或切换 |
| 全局 | `Esc` | 关闭浮层 |
| 通用 | `Ctrl+,` | 打开设置 |
| 启动器 | `↑` `↓` | 移动选中 |
| 启动器 | `Enter` | 打开 |
| 启动器 | `Shift+Enter` | 管理员打开 |
| 启动器 | `Ctrl+Enter` | 打开所在位置 |
| 启动器 | `Ctrl+C` | 复制路径/URL |
| 启动器 | `Tab` | 补全为前缀模式 |
| 剪贴板 | `↑` `↓` / `PgUp` `PgDn` | 移动 |
| 剪贴板 | `Enter` | 粘贴 |
| 剪贴板 | `Ctrl+Enter` | 仅复制 |
| 剪贴板 | `Ctrl+P` | 置顶切换 |
| 剪贴板 | `Delete` / `Shift+Delete` | 删除 / 永久删除 |
| 剪贴板 | `Ctrl+Shift+Delete` | 打开清空历史确认（`Enter` 保留收藏，`Ctrl+Enter` 全部清空，`Esc` 取消） |
| 剪贴板 | `Tab` / `Shift+Tab` | 切换类型过滤 |
| 转换 | `↑` `↓` | 移动动作 |
| 转换 | `Enter` | 替换原文 |
| 转换 | `Ctrl+Enter` | 仅复制 |
| 转换 | `1`–`9` | 直接执行第 N 项 |
| 输入框 | `Ctrl+A` / `Ctrl+C` / `Ctrl+V` | 标准编辑行为 |

规则：

- 焦点永远在输入框，方向键由列表拦截（`preventDefault`）。
- 鼠标悬停不改变选中项（避免误操作），点击才选中。
- 滚轮只滚动列表，不移动选中。
- 输入法组合期间（`compositionstart` 到 `compositionend`）不响应方向键与回车。

## 6. 状态

| 状态 | 呈现 |
|---|---|
| 加载中 | 3 行骨架，透明度 40%，不显示 spinner |
| 空历史 | 图标 + 「还没有记录」+ 「复制任意内容后会出现在这里」 |
| 无搜索结果 | 「没有找到 “xxx”」+ 「Enter 用网页搜索」（启动器） |
| 未选中文本 | 「未检测到选中文本」+ 「请先选中文字再按 Alt+X」，3 秒后自动关闭 |
| 索引构建中 | 底部提示条右侧显示「索引中 1,204/8,000」 |
| 错误 | 提示条变 `--warn`，显示中文原因与下一步；不弹模态框 |
| 暂停记录 | 输入区顶部细条 + 「暂停记录中，Alt+V 仍可粘贴」 |

## 7. 设置窗口

- 左侧导航 200px：常规 / 热键 / 剪贴板 / 搜索 / 隐私 / 关于。
- 右侧内容最大宽度 560px，分组卡片式，每组标题 13px 600。
- 每项一行：左侧标题 + 说明（11px `--text-muted`），右侧控件。
- 热键录制：控件显示 `Alt+Space`，点击后变「请按下组合键…」，`Esc` 取消。
- 危险操作（清空历史、恢复默认）用 `--danger` 文字按钮 + 二次确认对话框。
- 关于页显示版本、构建时间、数据目录（可点击打开）、条目数与占用。

## 8. 动效

- 显示：120ms，透明度 0→1 + 位移 4px→0（`ease-out`）。
- 隐藏：80ms 淡出，不做位移动画。
- 高度变化：120ms（内容切换时），列表滚动不做动画。
- 系统开启「减少动画」时全部改为即时切换。
- 禁止：弹跳、缩放、模糊过渡。

## 9. 可访问性

- 对比度：正文 ≥ 4.5:1，次要信息 ≥ 3:1。
- 可聚焦元素有 2px `--accent` 焦点环（`outline-offset: 2px`）。
- 所有图标按钮有 `aria-label`；列表行有 `aria-selected`。
- 不依赖颜色单独传达状态（截断/置顶同时有文字或图标）。
- 屏幕阅读器：模式切换时播报标题与结果数量（`aria-live="polite"`）。

## 10. 实现约定

- 全部使用 Tailwind + CSS 变量；颜色不写死在组件里。
- 列表虚拟化：可见行 ≤12，首版不做虚拟滚动；超过 200 条只渲染可视区域（`IntersectionObserver` 或分页）。
- 图标：本地 SVG（Lucide 风格），不引图标库；尺寸统一 20px，`stroke-width: 1.75`。
- 图片通过 Tauri `asset` 协议加载 `blobs/` 与缩略图，禁止 base64 内联大图。
- 组件命名：`ItemRow`、`PreviewPane`、`KeyHint`、`EmptyState`、`Skeleton`。
