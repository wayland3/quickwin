## 设计评审（1 轮）

结论 PASS。NONBLOCK：

1. UWP 枚举失败按 ARCHITECTURE §9 应降级 `Get-StartApps` 快照，实现为「空 + warn」且未登记
   - 处理：登记为偏差与遗留（快照降级留给 T-302 刷新任务评估），见 TASKS.md 实现备注
2. 同 key 多来源时 name/icon 取舍未定义
   - 处理：`build_index` 固化来源优先级 + 名称字典序 + 图标优先的稳定 tie-break，并补测试
3. `icon_path` 存 `.lnk` 图标位置字符串，前端 asset 协议无法直接渲染
   - 处理：登记偏差（图标提取/占位图标随启动器 UI 任务 T-303/T-304）

## 实现评审（1 轮）

结论 PASS。NONBLOCK（登记遗留）：

1. **原始路径未展开环境变量**（`platform/apps.rs` `SLGP_RAWPATH`）
   - 目标含 `%SystemRoot%` 等未展开变量时 `is_file()` 判失败，可能少量漏项
   - 处理：登记遗留，后续按需展开或改短路径兜底
2. **图标回退到 target**（`services/appindex.rs`）
   - 以 `cmd.exe /c` 类启动器为目标时图标可能指向非实际程序
   - 处理：可接受，登记遗留
3. **逐候选 `is_file()` 磁盘 IO**（`services/appindex.rs` `is_usable`）
   - 冷盘 + 大量候选可能拖慢重建；本机实测 1.4s 冷启动 / 0.35s 预热，未超 2s
   - 处理：接近门限时再评估缓存 stat
