# T-102 浮层窗口管理器

**实现模型**：qwen3.7-plus
**评审模型**：GLM-5.3
**评审日期**：2026-10-27
**结论**：PASS（第 2 轮修复后）

## 初次评审问题（FAIL）

1. **DPI 换算错误**：用 `GetDpiForWindow` 取的是窗口当前所在显示器的 DPI，不是目标显示器
2. **焦点管理缺失**：没有 no-activate 显示方案，没有焦点记录/恢复机制
3. **状态机缺失**：show/hide 无状态机，重入与动画时序竞争会导致残影/闪烁

## 第 2 轮评审问题（FAIL）

1. **【阻断】全屏检测误杀**：不能用"窗口矩形 == 显示器矩形"判断独占全屏，F11 浏览器/网页全屏也会被拦截
2. **【高】跨 DPI 屏坐标基准错误**：`set_position(Logical)` 按窗口当前所在显示器的 DPI 换算，跨屏移动时会错位
3. **【中】状态机动画时序未定义**：Showing 中收到 hide/blur 时的处理未定义

## 修复措施

### 第 1 轮修复
1. ✅ 改用 `GetDpiForMonitor(hmonitor, MDT_EFFECTIVE_DPI)` 获取目标显示器 DPI
2. ✅ 添加焦点记录（`GetForegroundWindow`）和恢复预留（T-104 实现）
3. ✅ 实现状态机（Hidden/Showing/Shown/Hiding），处理重入和动画时序

### 第 2 轮修复
1. ✅ 删除事前全屏拦截，直接 show；独占全屏提示降级为事后兜底
2. ✅ 使用逻辑像素坐标（tauri 自动处理 DPI 换算）
3. ✅ 补全状态机转换：Showing + hide → 立即转 Hiding；blur 用 Rust 侧 `WindowEvent::Focused(false)`
