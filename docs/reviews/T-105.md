## 第 1 轮评审问题

1. **SendInput 失败语义混淆**：
   - 返回 0（零注入）vs 部分注入（0 < ret < len）要区分
   - 部分注入重试会导致重复字符
   - UIPI 场景应返回 ElevatedTarget，不是 Internal

2. **调用入口缺失**：
   - 模块交互写了 commands::input_*，但改动文件没有 commands
   - 本任务是纯 platform 封装，不需要 command
   - 手测入口缺失，验收无法执行
   - 需要明确阻塞属性，禁止在 async 中直接调用

3. **send_combo 契约过宽**：
   - 未定义合法语法
   - 解析失败应返回参数错误，不是 Internal
   - 建议收窄 API 面，只用 send_copy/send_paste

## 修复措施

1. ✅ 失败处理三分支：
   - 零注入 → UIPI 检查 → ElevatedTarget
   - 部分注入 → Internal（不重试）
   - 零注入非 UIPI → 重试一次

2. ✅ 明确本任务纯 platform 层：
   - 删除 commands::input_* 交互描述
   - 新增 tests/input_manual.rs 作为手测入口
   - 函数文档标注「阻塞函数，禁止在 async 中直接调用」

3. ✅ 收窄 API 面：
   - 不暴露通用 send_combo
   - 只提供 send_copy/send_paste
   - 与 T-105 任务描述偏差已记录在实现备注
