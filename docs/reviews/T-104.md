## 第 1 轮评审问题

1. **capture 时机缺失**：必须在 show 之前（Hidden→Showing 时）capture，blur 隐藏不应 restore
2. **提权检测不可靠**：OpenProcess ACCESS_DENIED 会漏报，改用 TokenElevation
3. **restore 健壮性不足**：需要 IsWindow 校验、记录子窗口、spawn_blocking 执行
4. **hide 语义未区分**：UserCommand 带恢复，Blur/ModeSwitch 不带恢复

## 修复措施

1. ✅ capture 时机：仅 Hidden→Showing 时调用，失败降级为 None
2. ✅ 提权检测：TokenElevation 为主 + AttachThreadInput 返回值检查
3. ✅ restore 健壮性：IsWindow 校验、子窗口 SetFocus、spawn_blocking 执行
4. ✅ hide 语义区分：UserCommand 带恢复，Blur/ModeSwitch 不带恢复
