# 交叉评审记录

本目录存放每个任务的交叉评审记录。

## 文件格式

每个文件命名为 `T-<id>.md`，格式如下：

```markdown
# T-<id> <任务名称>

**实现模型**：qwen3.7-plus
**评审模型**：GLM5.3 / kimi-3.1
**评审日期**：YYYY-MM-DD
**结论**：PASS / FAIL

## 风险与处理

1. **风险标题**
   - 问题：描述评审中发现的风险
   - 处理：说明如何处理（已修复 / 接受风险 / 记录到需求池）
   - 验证：如何验证处理有效

2. ...

3. ...

## 遗留建议

- 后续可改进的事项（非阻塞）
```

## 规则

- 结论必须为 PASS 才能提交。
- FAIL 或无法执行 → 任务标 `[!]`，禁止提交。
- `TASKS.md` 实现备注中引用对应的评审文件：`详见 docs/reviews/T-<id>.md`。
